# Frequently asked questions / Časté dotazy

### Is Enoa-Engine II a real project?
Yes. Enoa-Engine II is an in-house C++17 game-engine and editor project being developed by EnoaSoft. This repository serves as its public project description.

### Is it related to Nintendo's Super Engine or Noah Engine?
No. The name **Enoa-Engine II** refers specifically to EnoaSoft's independent technology project. Similar-sounding search results refer to unrelated products.

### Is Enoa-Engine II open source?
No. The project's source and binaries are private. This information repository is public, but does **not** provide an open-source license.

### Is Silent Patrol: Vietnam a separate game from the Unreal Engine version?
No. **Silent Patrol: Vietnam is one game with parallel implementations** in Unreal Engine 5 and Enoa-Engine II. This is a technology strategy, not an announcement of two games.

### Can players download the game now?
No public game download or release date is announced in this repository.

### Can the engine package standalone games?
A development build/export UI and exported game menu have been shown. The development team reports that a standalone executable ran in its test environment. This should not be interpreted as a completed Windows distribution/compatibility certification.

### Are performance numbers shown in the images trustworthy?
The LOD comparison illustrates a change in rendered triangle count in a particular test. The images were captured through Wine and must not be used to infer native Windows FPS or GPU performance.

### Where can I learn more?
Official EnoaSoft website: https://enoasoft.cz. This repository should be kept updated with confirmed public milestones.
