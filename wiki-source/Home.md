# Enoa-Engine II — Official Wiki

**An independent C++17 3D game engine and editor in development at EnoaSoft.**

Enoa-Engine II is an in-house technology project focused on developing interactive 3D worlds and tactical first-person games. The technology is actively evolving; this wiki documents the **publicly presented scope**, not a public SDK or a finished commercial engine.

## At a glance

| Topic | Publicly documented scope |
| --- | --- |
| Core | C++17 |
| Editor | Windows-oriented desktop editor |
| Rendering | Direct3D 11, PBR, shadows, parallax materials, LOD |
| Content | glTF/GLB, Blender workflow, terrain, vegetation |
| Gameplay | FPS controller, collision, Lua, basic AI navigation/perception, audio |
| Presentation | In-game menus, cutscenes, game packaging/build workflow |
| Availability | Private, proprietary development; no public engine SDK |

**Development environment:** Published screenshots were captured through **Wine**; FPS overlays are not native-Windows benchmarks.
