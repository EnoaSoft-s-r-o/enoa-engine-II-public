# Official Wiki Source

This directory is the **public, GitHub Wiki-ready Markdown source** for Enoa-Engine II.

**Important:** The GitHub Wiki is stored separately from the main Git repository. Committing files here does **not** publish them to the Wiki tab automatically.

The repository Wiki feature is enabled. To publish these pages into the native GitHub Wiki:
1. Open https://github.com/EnoaSoft-s-r-o/enoa-engine-II-public/wiki and create the initial **Home** page in the GitHub UI.
2. On a computer, clone `https://github.com/EnoaSoft-s-r-o/enoa-engine-II-public.wiki.git`.
3. Copy the Markdown pages from this directory into the clone's **root** (including `Home.md` and `_Sidebar.md`; exclude this README).
4. Commit and push the wiki clone. No engine sources, assets or secrets are needed.

This folder contains the same content for review and history. No `GITHUB_SETUP.md` or `FACEBOOK_POST_CZ.md` belongs here.

**Image references** point to images in the public information repository. Status claims are conservative and should be updated only after corroborated milestones.
