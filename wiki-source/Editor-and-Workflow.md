# Editor & Workflow

The Enoa-Engine II editor is a Windows-oriented desktop application with a Direct3D 11 viewport and a workflow for creating and managing game projects.

## Features shown in development material

- Project opening and basic project setup.
- Scene hierarchy / object collections and an Inspector.
- Object transform tools, selection and scene navigation.
- Asset browser for models and textures.
- Terrain, material and atmosphere panels.
- Integrated Poly Haven browser and Blender-oriented asset pipeline.
- Tools for menus and cinematic content, as described in the project's public overview.
- A game build/export interface for packaging project content.

![Development editor screenshot](https://raw.githubusercontent.com/EnoaSoft-s-r-o/enoa-engine-II-public/main/media/screenshots/editor-scene.jpg)

The interface and functionality are **work in progress**. Earlier and newer screenshots represent different stages of development rather than a single final build.

## Availability

The editor is not available for public download in this repository. No public editor release date has been announced.
