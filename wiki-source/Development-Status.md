# Development Status & Testing

**Public information snapshot: November 2026.** Enoa-Engine II is in active development.

## What has been demonstrated

| Capability | Public evidence | Boundary |
| --- | --- | --- |
| Scene editor | Editor UI screenshots | Evolving development UI |
| PBR, parallax, atmosphere | Comparison and viewport images | Visual demonstration, not shipping QA |
| Automatic LOD | 5.23M vs 0.82M triangle screenshot | Counts only, not a native FPS benchmark |
| Terrain & foliage | Development scenes and editor controls | Test content, not final gameplay art |
| Game export & menu | Build dialog and game-menu screenshot | Team-reported standalone execution; no public installer |
| Gameplay systems | Engine documentation | Different levels of implementation/validation |

## Testing disclaimer

All screenshot sets provided for this public documentation were captured via **Wine**. Low or high reported FPS values on these captures cannot be extrapolated to native Windows. The team still needs documented tests on target PC hardware for shipping-quality claims.

## Not announced

- Public engine or SDK release.
- Public distribution of engine source/binaries.
- Completed, independently verified Windows release.
- Release date for **Silent Patrol: Vietnam**.
