# About Enoa-Engine II

**Enoa-Engine II** is a proprietary C++17 3D game-engine project developed by **EnoaSoft**. The team is creating a game-technology stack with its own editor, rendering systems, tools for scene and asset creation, and gameplay components.

## Why it exists

The aim is greater control over rendering, gameplay architecture, level authoring, optimization and long-term development of EnoaSoft's games. The first major intended use case is **Silent Patrol: Vietnam**, a tactical FPS set during the Vietnam War.

The project is distinct from, and not affiliated with, similarly named engines or tools.

## What it is not

- Not a public open-source engine.
- Not a currently announced downloadable SDK or editor release.
- Not the Silent Patrol game itself; the engine and game are different projects.
- Not a declaration that every described feature is production-ready.

## Where development stands

The team has shown a scene editor, material and terrain tools, foliage, automatic LOD comparisons, and a game build/export workflow. Additional systems are described in engineering materials. See [[Development-Status]] for the distinction between demonstrated behavior, reported tests and future validation.
