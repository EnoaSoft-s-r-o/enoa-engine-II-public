# Silent Patrol: Vietnam

**Silent Patrol: Vietnam** is a tactical first-person game in development at EnoaSoft, set in the context of the Vietnam War.

## One game, two technical implementations

The game has **two parallel technical paths**:

1. **Unreal Engine 5** — used for game development and testing.
2. **Enoa-Engine II** — a separate implementation of the **same game** on EnoaSoft's proprietary technology.

This does **not** mean two separate games or a confirmed migration date. The long-term intention is to reduce reliance on Unreal Engine once the proprietary engine is sufficiently mature.

## Project boundaries

The public Enoa-Engine II repository documents engine technology, **not** the private game project. Development screenshots featuring sample scenes and test geometry must not be taken as the game's final environments.

No public release date or download is announced here.
